如何思考这类问题？验证dijikstra
1. 识别动态操作
明确问题中哪些操作会导致边权变化（如CF1473E的“减最大边、加最小边”）。

将操作转化为状态维度（如布尔变量表示是否已执行操作）。

2. 设计状态表示
状态需要包含：

当前节点 u。

动态操作的完成情况（如 a 和 b）。

例如：

dist[u][a][b]：从起点到 u，是否已减边 (a)、是否已加边 (b) 的最小权值。

3. 确定状态转移 //状态转移一定不能漏
对每条边 (u, v, w)，枚举所有可能的操作组合：

不操作：dist[v][a][b] = dist[u][a][b] + w。

减边（若允许）：dist[v][1][b] = dist[u][0][b]。

加边（若允许）：dist[v][a][1] = dist[u][a][0] + 2*w（因为 +w -w 的净效应是 +w）。

4. 验证最优子结构  //!!!!
确保状态转移满足最优子结构：(当前状态的最优解由某个前驱状态的最优解决定。)!!!!!!

在Dijkstra中，每次从优先队列取出的状态一定是当前的最小值，保证无后效性。

！！！！反证法,假设由非优路径到达P，发现优路径到P更短,则结论错误，得证最优子结构

如果发现是DAG图，可以使用DAGdp,
    按拓扑序从前往后 DP（正向递推）或者 记忆化dfs（有反向关系时，后置递归到前）
