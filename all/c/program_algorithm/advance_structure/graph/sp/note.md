1. 最长路径问题（DAG中）
目标：在无环有向图（DAG）中，求从源点到终点的最长路径。

修改方法：

将边的权重取相反数，用Dijkstra求最短路径（需无负环）。

或直接按拓扑排序动态规划（更高效）。

限制：在普通图中（可能有环），最长路径是NP-Hard问题。

2. 最大可靠路径（Max-Reliable Path）
目标：路径的可靠性是各边成功概率的乘积，求成功概率最大的路径。

修改方法：

将概率取对数（转为加法），边权为 -log(p)，用Dijkstra求最小权值和。

或用最大堆代替最小堆，直接贪心选择最大概率。

3. 路径数量统计
目标：在求最短路径的同时，统计到每个节点的最短路径数量。

修改方法：

维护一个计数数组count[]，初始化 count[s]=1。

松弛时，若找到更短路径，更新距离并重置计数；若距离相等，累加计数。

4. 边权限制下的路径（Constrained Shortest Path）
目标：在总边权不超过限制的条件下，优化另一指标（如时间、成本）。

修改方法：

使用多维距离数组（如dist[node][cost]），记录不同成本下的最优解。

类似背包问题的动态规划思想。

5. k-最短路径（K-Shortest Paths）
目标：求前k条最短路径（非简单路径可能重复）。

修改方法：

Yen's算法：基于Dijkstra，逐步删除边并重新计算。

Eppstein's算法：更高效的预处理方法。

6. 最宽路径（Widest Path / Bottleneck Path）
目标：路径的带宽由最小边决定，求带宽最大的路径。

修改方法：

用最大堆代替最小堆，优先扩展当前带宽最大的路径。

类似Prim算法或最大生成树的思想。

7. 多目标优化（Pareto最优路径）
目标：同时优化多个指标（如时间、成本、距离）。

修改方法：

维护每个节点的Pareto前沿（一组非劣解）。

扩展时比较新解是否被已有解支配。

8. 最短路径树（Shortest Path Tree）
目标：构建从源点到所有其他节点的最短路径构成的树。

修改方法：

在Dijkstra过程中记录前驱节点，最终反向构建树。

9. 动态图或实时更新
目标：处理边权动态变化的图（如交通网络）。

修改方法：

动态Dijkstra：增量更新受影响的节点。

或使用更高级的算法（如A*、**D* Lite**）。

关键点总结
权重转换：通过数学变形（如取对数、取负）将问题转化为最短路径。

数据结构扩展：用多维数组或自定义优先级队列维护额外信息。

动态规划结合：如约束条件下的路径问题。

这些变种体现了Dijkstra算法的灵活性，但需注意问题的性质（如是否有负权、环、多目标等）以选择合适的变体。

以下是结合Dijkstra算法变种的经典题目，涵盖洛谷（Luogu）、Codeforces和Atcoder平台的题目，按变种类型分类整理：

1. 最长路径（DAG）
题目：P1807 最长路 - 洛谷

题意：给定DAG，求1到N的最长路径。

解法：拓扑排序+DP 或 边权取反后Dijkstra（需无环）。

2. 最大可靠路径（概率乘积最大）
题目：CF1005D（Polycarp and Div 3）

变形题：可将数字序列转为图的边权（概率），求路径最大乘积。

推荐题：P1576 最小花费 - 洛谷

题意：边权为手续费百分比，求使剩余金额最大的路径。

3. 路径数量统计
题目：P1144 最短路计数 - 洛谷

题意：无权图（边权为1），求源点到各点的最短路径数量。

解法：BFS或Dijkstra + count[]数组维护。

4. 边权限制下的路径（约束最短路径）
题目：ABC192E - Train - Atcoder

题意：在时间限制下，求最小花费的路径。

解法：二维dist[time][cost]动态规划 + Dijkstra。

5. k-最短路径
题目：P2865 [USACO06NOV] Roadblocks G - 洛谷

题意：求次短路径。

解法：维护到每个点的最短和次短距离。

6. 最宽路径（Bottleneck Path）
题目：CF20C Dijkstra? - Codeforces

变形：可将边权视为带宽，求最大带宽路径。

经典题：UVA10048 - Audiophobia

题意：求路径中最大边权的最小值（最小化瓶颈）。

7. 多目标优化（Pareto最优）
题目：ABC245E - Wrapping Chocolate - Atcoder

变形：可将巧克力和盒子视为图的节点，多维度贪心。

推荐：P2761 软件补丁问题 - 洛谷

状态压缩+多维最短路。

8. 动态图/实时更新
题目：CF1473E - Minimum Path - Codeforces

题意：路径权值可减去一条边、加一条边，求最短路。

解法：多维Dijkstra，维护是否已加减边权。

9. 最短路径树相关
题目：P4180 [BJWC2010] 严格次小生成树 - 洛谷

需先求MST，再枚举非树边构造次小生成树。

最短路径树构建：CF1005F - Berland and the Shortest Paths

要求输出所有可能的最短路径树。

10. 负权图处理（SPFA优先）
题目：P3385 【模板】负环 - 洛谷

注意：Dijkstra不能处理负权，但可用SPFA检测负环。

变形：ABC137E - Coins Respawn - Atcoder

边权可负，但需判断正权环。

刷题建议
从模板题入手：先掌握标准Dijkstra（如P4779 【模板】单源最短路径 - 洛谷）。

逐步扩展变种：如先做最短路计数（P1144），再做次短路（P2865）。

注意算法限制：Dijkstra无法处理负权，遇到负权需转SPFA或Bellman-Ford。
